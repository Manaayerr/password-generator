# Password Generator | مولد كلمات المرور

### Description / الوصف
**EN:** A simple web application to generate secure and random passwords. Built with HTML, CSS, and JavaScript.
**AR:** تطبيق ويب بسيط لإنشاء كلمات مرور آمنة وعشوائية، تم تطويره باستخدام HTML و CSS و JavaScript.

### Technologies Used / التقنيات المستخدمة
* HTML5
* CSS3
* JavaScript

### How to use / طريقة الاستخدام
1. Open `index.html` in your browser.
2. Click the generate button to get a new password.
---
1. افتح ملف `index.html` في متصفحك.
2. اضغط على زر التوليد للحصول على كلمة مرور جديدة.
